# PPT 制作规范 Skill

一套可复用的 PPT 制作规范 Skill，统一「黑体标题 + 宋体正文 + 行距 1.3–1.5」，规范图文三式排版、精美文本框、智能图形、图带字合成图与配图生成适配，并附精美度进阶方法论与 5 页完整示范。

## 核心规范

- **字体**：标题黑体（SimHei）、正文宋体（SimSun）、数字/英文 Arial
- **字号自适应**：标题 24–40pt、正文 14–20pt；行距 1.3–1.5（默认 1.4）
- **图文三式**：左图右文 / 上下结构（图上居中）/ 左文右图
- **文字呈现**：独段文字 → 精美文本框；多段文字 → 智能图形或图带字合成图
- **图片融入**：图片底色与主页面色调统一，或抠图透明融入（禁止白底方块图）
- **配图生成**：Prompt 模板 + 抠图/调色/同色系图卡适配 + 服务不可用降级链
- **精美度**：调研 20+ 精品 PPT 网站沉淀的 7 章方法论（色彩系统、字体系统、信息图形化、动效与母版等）

## 目录结构

```
.kun/skills/ppt/
├── SKILL.md                  # 主规范（第 1–7 章）
└── templates/
    ├── text-image-card.svg   # 图带字卡片模板（可复用）
    └── image-prompt.md       # 配图生成 Prompt 库
demo/
├── preview.html              # 5 页完整示范（可直接浏览器打开）
├── page1.png ~ page5.png     # 每页高清导出图
├── slide1.html ~ slide5.html # 单页源文件
└── build.py                  # 拆分/审计脚本
```

## 使用

1. 把 `.kun/skills/ppt/` 放入工作区（或 Kun 用户 skills 目录）。
2. 让 AI 按本 skill 做 PPT / 改 PPT 即可，系统会自动遵守规范并逐项质检。
