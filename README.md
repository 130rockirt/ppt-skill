# PPT 制作规范 Skill

一套可复用的 PPT 制作规范 Skill，统一「黑体标题 + 宋体正文 + 行距 1.3–1.5」，规范图文三式排版、精美文本框、智能图形、图带字合成图、配图生成适配，并附精美度方法论与真实精品案例拆解。

## 核心规范

- **字体**：标题黑体（SimHei）、正文宋体（SimSun）、数字/英文 Arial
- **字号自适应**：标题 24–40pt、正文 14–20pt；行距 1.3–1.5（默认 1.4）
- **图文三式**：左图右文 / 上下结构（图上居中）/ 左文右图
- **文字呈现**：独段文字 → 精美文本框；多段文字 → 智能图形（并列卡片组）或图带字合成图
- **母版导航条**：多页 PPT 顶部固定板块导航条（当前板块高亮）
- **图片融入**：图片底色与主页面色调统一，或抠图透明融入（禁止白底方块图）
- **配图生成**：Prompt 模板 + 抠图/调色/同色系图卡适配 + 服务不可用降级链
- **精美度方法论**：调研 20+ 精品 PPT 网站沉淀的色彩系统、字体系统、信息图形化、动效与母版等
- **实战案例拆解**：逐页解析真实精美说课 PPT，反哺配色色阶表、结构骨架、三种版式、黄金搭配骨架与说课类版式预设

## 目录结构

```
.kun/skills/ppt/
├── SKILL.md                  # 主规范（第 1–8 章）
└── templates/
    ├── text-image-card.svg   # 图带字卡片模板（可复用）

```

## SKILL.md 章节速览

1. 字体与文本规范（黑体/宋体/行距/重点加粗/母版导航条）
2. 图文搭配三式（左图右文 / 上图中下 / 左文右图 + 图片融入规则）
3. 文字呈现规则（精美文本框 / 智能图形 / 并列卡片组参数）
4. 图带字合成图生成方法
5. 生成适配图片（Prompt 模板 / 适配规则 / 降级链）
6. 制作与质检流程
7. 精美度进阶方法论（场景风格 / 页面角色 / 色彩字体系统 / 信息图形化 / 动效母版 / 参考资源）
8. 实战案例拆解（真实说课 PPT 的配色/结构/版式/黄金骨架/说课类预设）

## 使用

1. 把 `.kun/skills/ppt/` 放入工作区（或 Kun 用户 skills 目录）。
2. 让 AI 按本 skill 做 PPT / 改 PPT 即可，系统会自动遵守规范并逐项质检。
