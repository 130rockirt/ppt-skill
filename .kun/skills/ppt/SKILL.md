# PPT 制作规范 Skill

## 何时使用

- 用户要求创建、修改或美化 PPT / 演示文稿时。
- 用户提到「黑体、宋体」「行距 1.3–1.5」「图配文」「文本框 / 智能图形 / 图带字」等排版要求时。

## 1. 字体与文本规范

| 元素 | 字体 | 备注 |
|---|---|---|
| 标题 | 黑体（SimHei） | 一律黑体，不用其他中文字体 |
| 正文 | 宋体（SimSun） | 一律宋体 |
| 数字/英文 | Arial 或 Times New Roman | 与中文混排时跟随邻近中文基线 |

- **字号自适应**：标题 24–40pt、正文 14–20pt。按文本量自动递减，以「不溢出、不换行错乱」为底线；每页一个核心观点。
- **行距**：正文多行段落统一 1.3–1.5（默认 1.4）；标题行距 1.1–1.2。
- **对齐**：正文两端对齐（左右）；标题按版式居中或左对齐；数字右对齐。
- **重点强调**：重要文字一律加粗加黑——用黑体（SimHei）粗体 + 近黑色（建议 #1C2B3A），与正文形成清晰层级；主题强调色（如橙）只用于装饰条、标签、下划线，不用于正文关键词。
- **页内容量上限**：正文不超过 5 行或 80 字；超过则拆页或改用智能图形。
- **母版统一元素（多页 PPT 必做）**：在母版中固定一条**导航条**（顶部或侧边的板块标签，当前页所属板块高亮/变色，其余淡色），让听众始终知道「讲到哪了」。这是真实精品说课/汇报 PPT 的共性做法（见 §8）。

## 2. 图文搭配三式（每种版式都必须符合其一）

通用参数：图片区占版面 45–55%，文字区与图片区间距 4–6%，页面四周留 8–12% 安全边距。

### 式一：左图右文
- 图居左（约 50% 宽），文居右（约 45% 宽），两部分垂直居中。
- 适用：流程图、对比说明、示例展示。

### 式二：上下结构（图上居中，文下）
- 图上（约 55–60% 高）水平居中，正文在图片下方通栏。
- 适用：大幅图表、产品大图、数据可视化。

### 式三：左文右图
- 文居左（约 50% 宽），图居右（约 45% 宽），垂直居中。
- 适用：先给结论再给证据、引用配图。

> 判断顺序：先判断内容适合哪一式，再排版；不允许出现「文字压图、图文重叠、图在角落」等无规则排布。

**图片融入规则（必查）**：图片要么使用与页面主色同色阶的图卡底色（色调统一），要么抠图（透明背景）让主体直接融入页面并以柔和光晕 / 虚线圆环衬托；**禁止白底方块图直接贴到彩色页面上**。同一份 PPT 内两种手法可混用，但每种手法要贯彻到底。

## 3. 文字呈现规则

- **独段文字**（单个核心段落）→ 使用精美文本框：
  - 浅色圆角矩形填充（同主题色 5–10% 透明），细边框（1pt，主题色 30% 透明），可选柔和投影；
  - 内边距统一（上下 8–12px，左右 16–20px）；
  - 文本框内不再嵌套其他图形。
- **多段文字**（≥2 段、并列要点、流程、对比）→ 使用与内容匹配的智能图形：
  - 要点并列 → 列表/矩阵形；
  - 流程/步骤 → 流程箭头形；
  - 循环/周期 → 循环形；
  - 对比 → 双栏/对比形；
  - 全文所有智能图形使用同一套配色方案。
- **并列卡片组标准参数**（3–6 个并列要点时的默认做法，见 §8）：
  - 每个卡片 = 1 个小图标 + 1 行小标题（黑体加粗）+ 2–3 行说明文字（宋体）；
  - 卡片浅色底 + 圆角 + 细边框，等宽等高、横向均分、间距一致；
  - 图标全篇同一线性风格、同一尺寸、同一主题色；
  - 3 个并排一行，4–6 个并排一行或两行（每行 ≤ 3 个）；
  - 流程类卡片之间用箭头/连线串联，强化「先后/递进」关系。
- **智能图形的替代方案**：可直接生成「图带字」合成图（见第 4 节），用一张图取代 SmartArt 整体排版，前提是文字内容固定、不需要在 PPT 中修改。

## 4. 「图带字」合成图生成方法

按优先级选择：

1. **SVG 模板（文字精确）**：使用本 skill 自带的模板 `templates/text-image-card.svg`（卡片式图带字），修改其中文字与图片占位后导出为 PNG（宽 1600px 以上）再插入 PPT。
2. **代码渲染（复杂版式）**：用 HTML/CSS 排版文字与图形，截图或导出 PNG 后插入；保证字号 ≥ 14px 等效、行距 1.4。
3. **图像生成工具（真实图片素材）**：当需要照片/插画时调用图像生成工具生成主题配图，但生成图中的文字不可靠——真实文字层必须在 PPT 中用文本框单独叠加（位置、字号按第 1 节规范），生成图只保留纯图形区。

## 5. 生成适配图片（主题配图自动出图）

当需要**照片级或插画级真实图片**（而非矢量示意图）时，调用图像生成工具自动生成与页面色调统一的适配图片，并按下面规则落地。

### 5.1 Prompt 模板（直接复制改主题即可）

```
{主题描述}，{构图}，{配色}，{风格}，no text, no letters, no numbers, no watermark, high quality, consistent color grading
```

- **主题描述**：如 “a cheerful school campus at sunrise with students walking in”“a child setting a paper boat toward a lighthouse”
- **构图**：配合版式 —— 式一/式三左右分栏用 `wide / side composition`；式二大图居中用 `wide horizontal, centered subject`；独立方图用 `centered subject, negative space`
- **配色**：与页面主色阶一致，如 `deep teal #1F3A4E, warm amber #D97706, warm paper background`（把 token 色值直接写进 prompt 保证色调统一）
- **风格**：`clean flat vector illustration` / `minimal editorial` / `soft 3D render` / `photo realistic`（全篇统一一种）
- **负面约束**：`no text, no letters, no numbers, no watermark`（文字层必须回 PPT 叠加，生成图不留字）

详见 `templates/image-prompt.md`（含三式配图 prompt 示例）。

### 5.2 生成后适配规则

1. **抠图融入**：生成图默认带背景时，用 AI 抠图（如创客贴批量抠图 / remove.bg）去背，得到透明 PNG，再叠加柔和光晕 / 虚线圆环。
2. **色调统一**：生成图若色调偏冷/偏亮，统一调色（同一滤镜/色温/饱和度），避免一页鲜一页灰。
3. **同图卡底色**：不抠图时，让图卡底色取自主色阶同色系（与本页 `dark` / `cutout` 两种模式一致）。
4. **文字不回图**：生成图中的文字不可靠，真实标题/正文必须在 PPT 中用文本框单独叠加。

### 5.3 服务不可用时的降级链

图像生成服务超时 / 失败时，按此顺序降级，不中断交付：

1. 切换为**内联 SVG 矢量插画**（亲手绘制，配色与主题 token 完全一致，本次示范即此方式）。
2. 使用**图带字合成图**（§4）：用排版 + 图形承担视觉，弱化对真实图片的依赖。
3. 使用**装饰性图形**（几何点缀、光晕、圆环、抽象渐变），靠配色与排版撑起版面。

降级后仍必须满足「图片底色与主页面色调统一或抠图融入页面」的规则。

## 6. 制作与质检流程

1. **拆内容**：把页面内容划分为「标题 / 独段文字 / 多段文字 / 图片」。
2. **选版式**：按第 2 节三式选型；有图必用三式之一，无图用文本框或智能图形。
3. **套规范**：按第 1 节设置字体、字号、行距、对齐。
4. **配元素**：根据文字形态选择文本框或智能图形；多段文字优先考虑直接生成「图带字」合成图。
5. **质检清单**（逐项核对）：
   - [ ] 所有标题是黑体、所有正文是宋体？
   - [ ] 正文行距在 1.3–1.5 之间？
   - [ ] 文字未溢出、未压图、未贴边？
   - [ ] 每个图文页符合三式之一，且有明确间距？
   - [ ] 独段文字用了精美文本框；多段文字用了智能图形或合成图？
   - [ ] 图片底色与主页面色调统一，或已抠图透明融入页面（无白底方块图）？
   - [ ] 重要文字已加粗加黑（黑体粗体 + 近黑色）？
   - [ ] 全文智能图形配色统一？
   - [ ] 合成图文字清晰、字体风格与 PPT 一致？
   - [ ] 生成图片已按 §5 适配（抠图 / 调色 / 同色系图卡），文字层回 PPT 叠加？
   - [ ] 多页时已加母版导航条（当前板块高亮）？
   - [ ] 3–6 个并列要点用了标准卡片组（图标+标题+说明、等宽均分）？

## 7. 精美度进阶方法论（2026-09 调研 20+ 精品 PPT 网站后沉淀）

### 7.1 先定场景与风格

精品模板站（1ppt、优品 PPT、SlidesCarnival 等）都按「场景 × 风格 × 主色调 × 题材」组织模板，做任何 PPT 前先定这四件事：

- **场景决定页面骨架**：
  - 汇报/述职：封面 → 目录 → 现状 → 成果 → 问题 → 计划 → 总结/致谢
  - 路演 Pitch：封面 → 痛点 → 方案 → 市场 → 商业模式 → 竞争 → 团队 → 财务 → 规划
  - 教学课件：封面 → 学习目标 → 知识点 → 例题 → 练习 → 小结
  - 论文答辩：封面 → 选题背景 → 文献 → 方法 → 结果 → 结论 → 致谢
- **风格一次选定并贯穿**：简约 / 商务 / 中国风 / 水彩 / 手绘 / 卡通 / 渐变 / 科技 / 极简 / 3D 角色等，全篇只允许一种设计语言。
- **主色调先定**（参考优品按红/粉/紫/蓝/绿/黄/橙/棕/黑/灰组织模板）：全篇围绕单一主色调展开。

### 7.2 页面角色分明确（不是每页都塞满）

封面、目录/议程、章节过渡页、内容页、图表页、结尾页各司其职；章节过渡页统一版式、只换序号与标题，形成节奏感。SlidesCarnival 的 Agenda / Timeline / SWOT / Roadmap 模板即此理念。

### 7.3 色彩系统（高级感来源）

- 主色 ≤ 3 个 + 中性灰 2 层；同色系深浅成阶（从浅底到深底都要有可用色）。
- 低饱和更显精致：莫兰迪/雾蓝/暖灰；近黑用 #1C2B3A、米白用 #F6FAFE，避免纯黑纯白刺眼。
- 强调色占比 ≤ 10%，只用于引导线、标签、下划线、关键数字。
- 背景全篇统一（同一套底色/局部渐变贯穿），渐变只在同色系内进行。

### 7.4 字体系统（两种字体 + 五级字号阶梯）

标题体 + 正文字 + 数字体各一；字号阶梯至少五级：标签 12–14 / 标题 28–40 / 副题 18–24 / 正文 14–20 / 注释 10–12；标题加字距（letter-spacing），关键词加粗加黑（见第 1 节）。

### 7.5 文字信息图形化（多段文字 ≠ 一堆字）

TemplatesWise、PresentationGO 等站的素材分类本身就是方法论：把要点变成图形。

- 并列要点 → 列表卡 / 矩阵
- 有先后顺序 → 流程箭头 / 时间线
- 循环往复 → 循环图
- 占比 → 环形图；趋势 → 折线图；对比 → 柱状图；分布 → 散点图；漏斗 → 流程泳道
- 先选对图表类型，再美化（去网格线、加数据标签、统一配色）
- 图标全篇统一风格（同一线性或同一填充、同一圆角）

### 7.6 图片与素材（融入与统一）

- 场景照片统一调色（同一滤镜/色温/饱和度），避免一张鲜一张灰。
- 透明背景素材（PNG 抠图、3D 角色、统一风格插画）直接融入页面，必要时用 AI 抠图辅助（如创客贴批量抠图），并遵守第 2 节图片融入规则。

### 7.7 动效与母版（优雅的前提）

- 动画克制：每页 ≤ 3 处、同类元素同一动效、以进入动画为主、时长 0.3–0.5s。
- 母版统一：字体、配色、页码、页脚、logo 全部在母版预设（优品教程方法论）。
- 页面切换动画全篇统一（淡入淡出或推入，不用随机切换）。

### 7.8 精美度十查（在 §6 清单基础上补充）

- [ ] 全篇单一风格（字体/配色/图形语言）？
- [ ] 主色 ≤ 3 且同色系深浅成阶？
- [ ] 每页只有一个视觉焦点？
- [ ] 图片统一调色或已融入页面？
- [ ] 图标与插画风格全篇一致？
- [ ] 目录/过渡页/结尾页齐全且版式一致？
- [ ] 动画克制统一（每页 ≤ 3 处）？
- [ ] 母版已统一页码/页脚？
- [ ] 远看 3 秒能抓住重点（大标题 → 大图 → 少字）？

## 8. 实战案例拆解：从一份真实精美说课 PPT 学到的落地做法

来源：逐页渲染并解析一份 17 页小学信息科技说课 PPT《知识图谱来帮忙》（配色、矢量结构、文本全部实测提取）。以下是其精美的根因，已反哺为本 skill 的可执行条款。

### 8.1 配色：单色系 + 近黑，高级感来源

全篇只用一套**青绿色系**，同色系 6 档深浅成阶，无任何杂乱色：

| 色值 | 角色 |
|---|---|
| `#4B948E` | 主色（标题/边框/重点） |
| `#2A5C45` | 深绿（深色文字/深色块） |
| `#63B892` `#97D0B6` `#A1CDB3` | 中间过渡（图形/图标） |
| `#CFE2D6` `#C9D7CA` | 浅底/衬底 |
| `#252525` | 正文近黑（不用纯黑） |
| `#FFFFFF` | 卡片底/留白 |

**落地规则**：任何 PPT 都先定这样一张「主色 + 深浅 4–6 阶 + 近黑 + 白」的色阶表，全篇只从这张表取色。

### 8.2 结构骨架：说课/课件类的标准页面序列

封面 → 目录（6 板块）→ 板块内容页×N → **章节过渡页** → 环节内容页×N → 结尾（评价/反思）。
对应本 skill §7.1 的「教学课件」骨架，此处为说课细化版：

- 目录页列出 4–6 个板块（教材分析 / 学情分析 / 教学目标 / 教学策略 / 教学过程 / 教学评价）；
- 「教学过程」单独设一页**过渡页**，用流程图形列出全部环节（情境导入→探究新知→运用迁移→实践应用→总结升华）；
- 每个环节一页内容页。

### 8.3 布局：三种版式 + 母版导航条

每一页顶部都有**同一条板块导航条**（当前板块高亮、其余淡色），这是统一全篇的母版手法。内容区只用三种版式（与 §2 三式一致）：

- **版式 A 通栏卡片**：导航条 → 大标题 → 下方一个浅色通栏卡片装一段正文（用于概念阐述页）。
- **版式 B 多卡并列**：导航条 → 标题 → 3–6 个并列小卡片（用于四维目标、六种策略、三条反思等并列要点）。
- **版式 C 左右图文**：导航条（换为环节标签）→ 左图右文或左文右图（一边是示意图/软件截图，一边是「提问」气泡 + 「总结」卡片）。

### 8.4 文字 / 图片 / 智能图形的搭配黄金骨架

每个内容页几乎都是同一套组合（§1/§2/§3 的实战验证）：

> 顶部导航条（母版）→ 大标题（黑体加粗）→ **左：示意图/截图**（图片，浅色卡片装裱不裸贴）→ **右：提问气泡 + 总结卡片**（独段文字→精美文本框）→ 多要点时换为**并列卡片组**（多段文字→智能图形）。

- **文字层级**：大标题黑体深绿/近黑；正文宋体近黑 `#252525`、行距宽松；重点词加粗 + 主题绿高亮；「提问」全篇用统一绿色气泡格式。
- **图片**：全部扁平矢量插画/图标，配色取自同一色系；真实软件截图用浅色卡片装裱。
- **智能图形**：四维目标、六种策略、五条环节分别用并列卡片组 / 流程箭头组承载（见 §3 卡片组参数）。

### 8.5 内容层面的「情境统一」

全篇用**一个情境**（「时空日报实习记者」+《西游记》师徒关系）贯穿：导入、示例、任务、升华全是同一主题。设计 PPT 时，案例/配图/任务尽量围绕同一主线，让内容本身也「风格统一」。

### 8.6 可直接复用的「说课类」版式预设

做说课/课件/教学类 PPT 时，按此清单逐页产出（每页都落在 §2 三式 + §8.3 三版式内）：

1. 封面（式三或上下结构，主题插画 + 大标题）
2. 目录（4–6 板块并列卡片）
3–7. 五个板块各一页（概念页用版式 A，要点页用版式 B）
8. 教学过程过渡页（流程图形列环节）
9+. 每个环节一页（版式 C 左右图文：左示意/截图，右提问+总结）
末. 评价与反思（版式 B 并列卡片，含 1 条不足与改进）
